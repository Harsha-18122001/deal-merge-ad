# Deal Merge Ad

A Unity-based playable ad / mini-game project for Deal Merge.

## Project Details

- **Engine Version**: Unity 2022.3.62f2
- **Main Scene**: `Assets/Scenes/MoneySort Beach.unity`

## Getting Started

1. Open Unity Hub and click **Add**.
2. Select this project root folder (`deal-merge-ad`).
3. Ensure Unity Editor version **2022.3.62f2** (or compatible LTS) is selected.
4. Open the project and navigate to `Assets/Scenes/MoneySort Beach.unity` to run or edit the playable ad.
